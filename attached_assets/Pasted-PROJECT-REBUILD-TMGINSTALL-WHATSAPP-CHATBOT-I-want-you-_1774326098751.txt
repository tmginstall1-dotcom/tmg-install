QUOTE WORKFLOW TO IMPLEMENT
The chatbot must support our quote checklist flow properly.

Service types:
- installation
- dismantling
- relocation
- mixed service

The quote collection flow should gather:
1. customer name
2. contact number if needed
3. email
4. service type
5. residential or office/commercial
6. item list with quantity
7. brand / model if known
8. photos / attachments if available
9. pickup address if relocation
10. delivery address if relocation
11. floor level at each location
12. lift available or staircase only
13. preferred date / preferred time window
14. extra notes

QUOTE COLLECTION UX RULES
- Ask one question at a time
- If the customer already gave multiple answers in one message, parse and save all of them
- Let the customer type naturally
- Support photo uploads as part of the flow
- If customer sends text like “1 queen bed, 2 wardrobes, move from Punggol to Tampines, both have lift”, parse it intelligently
- After enough information is collected, show a clean summary and ask customer to confirm
- Once confirmed, create a quote lead in database
- Then respond with a professional acknowledgement that admin will review and confirm final quote if required
- If your system supports instant estimate, only show a safe pre-quote clearly labeled as estimate / subject to review
- Never present rough estimate as guaranteed final quote

QUOTE CHECKLIST LOGIC
Create strong extraction and validation for:
- quantity
- item names
- service type
- addresses
- floor / lift / stairs
- photos attached or not
- missing required fields

If missing details, the bot should ask smart follow-up questions.
Example:
- If relocation selected but no destination given, ask destination next
- If wardrobe mentioned but no size/door type, ask only if needed for pricing
- If office project with many items, collect basic summary and offer human follow-up
- If customer already sent photos, do not keep asking for the same thing

PRICING RESPONSE LOGIC
The bot must answer pricing questions in a safe and useful way:
- exact pricing only when simple, supported, and low-risk
- otherwise give “from” pricing or explain quote factors
- explain that final pricing depends on item type, quantity, access, floors, lift/stairs, transport, and photos
- use admin pricing catalog / rules, not hardcoded numbers
- where pricing confidence is low, do not guess

HUMAN HANDOFF RULES
Create clear escalation rules.
Escalate to human/admin when:
- customer asks for manager or human
- customer sounds upset
- pricing is unclear or disputed
- job is too large or commercial complex
- custom carpentry / special installation / unusual item
- same-day urgent request
- repeated misunderstanding

- FAQ confidence is low

- notify admin
