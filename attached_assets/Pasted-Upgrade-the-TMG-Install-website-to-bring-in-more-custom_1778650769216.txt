PHASE 2 — Quote Flow Improvements
Improve the estimate/quote process so customers trust it and complete it.

Required:
1. Make quote wording clear:
   - Submitting a quote request should not imply the customer is charged immediately.
   - Use wording like:
     “Submit request → TMG confirms details by WhatsApp → deposit secures your slot.”
2. Make deposit wording clear:
   - “Deposit after confirmation”
   - “Balance after completion”
3. Do not show surprise fees unless they are explained.
4. If stairs/floor/access fees exist, ask access questions first:
   - Lift available?
   - Floor level?
   - Any stairs or difficult access?
   - Parking/loading access?
5. Add or improve photo upload / photo prompt:
   - Encourage customers to upload/send furniture photos.
   - Explain that photos help TMG quote faster and more accurately.
6. Add “Not sure what to choose? Send photos on WhatsApp” option.

Connect the quote flow to the WhatsApp chatbot with a useful summary.

- Customer name
