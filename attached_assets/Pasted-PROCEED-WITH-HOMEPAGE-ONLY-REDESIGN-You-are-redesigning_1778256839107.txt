3D IMPLEMENTATION REQUIREMENTS

Create homepage-only component:

Must include:
"use client"

Use React Three Fiber.
Use simple geometry first.
Do not use heavy GLB models.
Do not add video.
Do not import huge assets.

Use:
- BoxGeometry for panels
- CylinderGeometry for screws/legs
- MeshStandardMaterial
- AmbientLight
- DirectionalLight
- Optional ContactShadows only if performance remains good

Use GSAP ScrollTrigger to drive the animation.
Clean up ScrollTrigger on component unmount.
Do not create memory leaks.

Important:

Use an id such as:

Canvas must not block clicking CTA buttons.
Set pointer-events carefully.
